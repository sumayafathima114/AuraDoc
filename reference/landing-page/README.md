# AuraDoc Landing Page

A standalone, responsive landing page for AuraDoc: a privacy-first forensic audio and document verification workbench.

## Run

Open `index.html` directly in a browser, or serve the folder with any static web server.

## Integration

The CTA routes currently point to `/signup`, `/signin`, and `/about`. In a Next.js app, replace these with the corresponding application routes.

## Design direction

Premium legal/forensic editorial aesthetic: deep navy, ivory, muted brass, serif display typography, restrained motion, evidence/workbench UI preview. No 3D hero, neon gradients, chatbot styling, or generic AI imagery.
